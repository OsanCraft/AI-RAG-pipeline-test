Info

The link to the Unstable Events Discord server is 
https://discord.gg/unstableevents
, and the server IP is UnstableEvents.net

There are a variety types of events in the Unstable Events such as: 

Mocap Events

Recording Events

Beta Testing

Plot Build Events

Thumbnail Events

Mocap Events

Mocap Events are events where players wander around a specific location in the server while getting recorded. They are often used for scenes used in the intros of a video. 

Recording Events

Recording Events are events hosted to get players into the actual videos and are actually canon to the Unstable SMP Lore. The first recording event was by 
SpokeIsHere
 for his 
Spoke Galactic Empire
 video.

Beta Testing

Beta Testing events are usually called by the admins (Horace, and Lukas) for a few players to test and debug the server. 

Plot Build Events

The Plot Build Events are in a seperate SMP (in the Unstable Events server) where players can build and their builds have a chance of actually getting in an Unstable video.

Thumbnail Events

Thumbnail Events are usually hosted to assist in making a thumbnail for an Unstable SMP video.   

Compatibility

In order to play on the Unstable Events server you must have:

Minecraft Java Edition (not a cracked version) 1.21.6-1.21.11+

Some events (usually beta testing events) support Java Edition 1.21.9 only.

Minecraft Bedrock Edition (the latest version supported by Geyser)

You also need to verify in-game.

History

The Discord server was created in June 11, 2025. The server was made public in June 25, 2025 after they had finished the server and got the necessary amount of boosts.
